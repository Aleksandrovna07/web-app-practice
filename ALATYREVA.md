\# 🌾 Бавлы: Активный гражданин



\*\*Веб-приложение для взаимодействия жителей с Исполнительным комитетом Бавлинского муниципального района Республики Татарстан.\*\*



Платформа позволяет оперативно подавать обращения, отслеживать их статус, просматривать новости, участвовать в опросах и видеть проблемные точки на карте района.

\## 📌 Функциональные возможности



| Модуль | Описание |

|--------|----------|

| 📝 \*\*Обращения граждан\*\* | Подача жалоб / предложений с указанием категории, описания и геолокации. Автоматическое добавление в список «Мои обращения» со статусом |

| 🗺️ \*\*Карта проблем\*\* | Интерактивная карта (Яндекс.Карты) с метками аварийных участков (ямы, свалки, отсутствие освещения) |

| 📢 \*\*Новости района\*\* | Лента официальных новостей и анонсов (субботники, отключения, прямые линии главы) |

| 📊 \*\*Опрос недели\*\* | Голосование по приоритетным направлениям бюджета (дороги, детские площадки, озеленение) |

| 🕒 \*\*График приёма\*\* | Контакты, адрес исполкома, часы работы и телефон горячей линии |

| 🔐 \*\*Авторизация\*\* | Демо-кнопка входа через Госуслуги (ЕСИА) — возможность интеграции |
